## PWA Features

Приложение поддерживает следующие PWA-фичи:

### 1. Biometric Authentication with WebAuthn API
Приложение поддерживает авторизацию с использованием биометрических данных (отпечатков пальцев, Face ID и т.д.) через WebAuthn API.

- **Как это работает**:
    1. На странице авторизации в мобильной версии есть кнопка "Register biometric", на которую нужно нажать в первую очередь 
        для сохранения своей биометрии для текущего замокированного пользователя Юлии Никитиной.
    2. Только после регистрации своей биометрии следует нажимать на кнопку "Face ID или Touch ID" для входа по только что сохраненным данным
    3. При последующих входах пользователь подтверждает свою личность через сканер отпечатков пальцев, распознавание лица или PIN.

- **Требования**:
    - Поддержка WebAuthn API браузером.
    - Устройство с биометрическим сенсором или иным средством защиты.
---

### 2. Button Feedback with Vibration API
Для улучшения пользовательского опыта при взаимодействии с интерфейсом используется **Vibration API** для тактильной обратной связи.

- **Особенности**:
    - В мобильной версии при переходе на страницу пользователя в правом верхнем углу появится шестеренка (кнопка страницы настроек).
    - Нужно нажать на шестеренку, чтобы попасть на страницу, где будут отображены PWA фичи, в том числе и кнопка для вибрации.

- **Требования**:
    - Устройство с вибромотором (обычно мобильные устройства).
    - Браузер с поддержкой **Vibration API**.

### 3. Network Information Monitoring with Network Information API
Приложение использует **Network Information API** для получения информации о сети пользователя.

- **Что отслеживается**:
    - **Тип сети**: определяет тип подключения (`wifi`, `cellular`, `ethernet`, `none` и др.).
    - **Эффективный тип сети**: показывает качество соединения (`4g`, `3g`, `2g`, `slow-2g`).
    - **Скорость соединения**: значение `downlink` в мегабитах в секунду (примерное).
    - **Задержка сети**: задержка (`rtt`) в миллисекундах.
    - **Экономия данных**: информация о включённом режиме экономии данных (`saveData`).

- **Как найти**:
    - В мобильной версии при переходе на страницу пользователя в правом верхнем углу появится шестеренка (кнопка страницы настроек).
    - Нужно нажать на шестеренку, чтобы попасть на страницу, где будут отображены PWA фичи, в том числе и информация о сети.
  
- **Требования**:
    - Браузер с поддержкой **Network Information API**.

### 4. Battery Status Monitoring with Battery Status API
Приложение отслеживает состояние батареи устройства с помощью **Battery Status API**.

- **Что отслеживается**:
    - **Уровень заряда**: процент заряда батареи (`battery.level`), значение от 0 до 1.
    - **Подключение к зарядке**: статус зарядки устройства (`battery.charging`), показывающий, заряжается ли оно.
    - **Время до полной зарядки**: отображение времени до полной зарядки (`battery.chargingTime`).
    - **Время до разрядки**: отображение времени до разрядки (`battery.dischargingTime`) в минутах. 

- **Как найти**:
    - В мобильной версии при переходе на страницу пользователя в правом верхнем углу появится шестеренка (кнопка страницы настроек).
    - Нужно нажать на шестеренку, чтобы попасть на страницу, где будут отображены PWA фичи, в том числе и информация о заряде.

- **Требования**:
    - Браузер с поддержкой **Battery Status API**.

### 5. Installation
Приложение настроено через `vite-plugin-pwa` и его можно скачать себе на устройство. 
- **Включает в себя следующее**:
  - **`injectManifest`**: используется стратегия внедрения манифеста (injectManifest), которая позволяет вам написать кастомный Service Worker и точно контролировать его поведение.
  - **`registerType: 'autoUpdate'`**: автоматическое обновление Service Worker без необходимости вручную управлять процессом обновления.
  - **`injectRegister: 'auto'`**: автоматическое добавление скрипта для регистрации Service Worker в приложении.
  - **Web App Manifest**: описывает метаданные PWA (дополнительно были сгенерированы и указаны файлы для предзагрузки в виде ресурсов: `favicon.ico`, `apple-touch-icon.png`, `mask-icon.svg`).
- **Как скачать**:
  - При открытии веб-приложения пояаляется диалоговое окно от браузера с предложением установки (зависит от настроек браузера).

### 6. File System Access API
Позволяет получить приложению доступ к файловой системе пользователя по нажатию кнопки. 
- **Как найти**:
  - На странице редактирования профиля доступна кнопка **`Добавить документ`**. При нажатии откроется файловая система и будет доступна возможность выбрать нужный файл или изображение.
  - На странице чата поддержки слева от `input` есть кнопка добавления файла. При нажатии откроется файловая система и будет доступна возможность выбрать нужный файл или изображение.

### 7. File Handling API
Приложение обрабатывает выбранные файлы, отправляет данные о них на сервер и кэширует их на стороне клиента.
- **Какие типы файлов обрабатываются**:
  - Все типы файлов и изображений. 
- **Какие данные о файле обрабатываются**:
  - Имя файла (`file.name`).
  - Размер файла (`file.size`).
  - Тип файла (`file.type`).
  - Последнее изменение (`file.lastModified`).

### 8. Storage API
Реализуется с использованием кэша для хранения файлов на клиентской стороне. Файлы сохраняются и извлекаются из локального хранилища. 
- **Что реализовано**:
  - **`addFileToCache`**: сохраняет файл в кэш, создавая для него URL на основе имени файла.
  - **`getCacheKeys`**: получение списка всех файлов, которые уже находятся в кэше.
  - **`downloadFileFromCache`**: пользователь может скачать файл, который хранится в кэше, напрямую из браузера (дополнительно обеспечен офлайн-доступ к сохраненным файлам).

### 9. MediaRecorder API
Позволяет обрабатывать голосовые сообщения в PWA-приложении с поддержкой офлайн-режима.
- **Что реализовано**:
  - **`startRecording`**: запись аудио через микрофон.
  - **`recordAudio`**: сохранение аудио на клиенте.
  - **`sendAudioMessage`**: отправка голосового сообщения.
  - **`handlePlayPause`**: воспроизведение аудио.
- **Как найти**:
  - На странице чата нажать на кнопку записи голосового сообщения, которая находится справа от `input` и нажать еще раз, чтобы остановить запись. 
  - Рядом с отправленным голосовым сообщением нажать на кнопку запуска голосового и нажать на паузу, если требуется.

### 10. Offline support
С использованием библиотеки Workbox описываются правила в `service-worker`, благодаря чему реализуется автономная поддержка приложения. 
- **Кэшированию подлежат**:
  - **Статические файлы**: `HTML`, стили, шрифты, скрипты, `manifest.json`.
  - **Изображения**: `.jpg`, `.png`, `.svg`.
  - **Get-запросы к**: `api/cards`, `api/goals`, `api/paymentSystems`, `api/contacts`, `api/users`, `api/documents`, `api/messages`.
- **Как найти**:
  - Отключить интернет и зайти в приложение.

Дополнительно реализован функционал отложенной отправки post-запросов. Таким образом, запросы помещаются в очередь и отправляются тогда, когда интернет-соединение будет восстановлено.


### 11. Device Memory Monitoring with Device Memory API
Приложение определяет класс устройства по объему установленной оперативной памяти с помощью **Device Memory API**.

- **Что отображается**:
  - **Объем оперативной памяти**: Пользователь увидит приблизительный объем оперативной памяти устройства в гигабайтах.
  - **Недоступность API**: Если API не поддерживается, пользователь увидит сообщение о его недоступности в текущем браузере.

- **Как найти**:
  - В мобильной версии при переходе на страницу пользователя в правом верхнем углу появится шестеренка (кнопка страницы настроек).
  - Нужно нажать на шестеренку, чтобы попасть на страницу, где будут отображены PWA фичи, в том числе и информация об объеме оперативной памяти устройства.

- **Как работает**:
  - Используется JavaScript свойство **navigator.deviceMemory**, чтобы получить информацию об оперативной памяти устройства.
  - Если устройство поддерживает **Device Memory API**, приложение отображает объем памяти, округленный до ближайшего целого числа.
  - Если API недоступно, выводится сообщение об отсутствии поддержки.

- **Требования**:
  - Браузер с поддержкой **Device Memory API**.

### 12. Network Status Monitoring with Online State
Приложение отслеживает состояние сети устройства с помощью **Online State API**.

- **Что отслеживается**:
  - **Состояние подключения**: Отслеживается информация о том, находится ли устройство в сети с помощью (`navigator.onLine`).
  - **Автоматическое обновление статуса**: Приложение автоматически обновляет отображение состояния при подключении или отключении от сети (события online и offline).

- **Как найти**:
  - В мобильной версии при переходе на страницу пользователя в правом верхнем углу появится шестеренка (кнопка страницы настроек).
  - Нужно нажать на шестеренку, чтобы попасть на страницу, где будут отображены PWA фичи, в том числе и информация о состоянии сети.

- **Как работает**:
  - При наличии сети отображается сообщение: **You are Online**.
  - При отключении сети отображается сообщение: **You are Offline**.

- **Требования**:
  - Браузер с поддержкой **navigator.onLine API** (совместим с большинством современных браузеров).

### 13. Geolocation API
Позволяет пользователю предоставлять свое местоположение веб-приложениям
- **Что реализовано**:
  - Определение координат: Используется **`navigator.geolocation`** для получения широты и долготы.
  - Обработка ошибок: Уведомления при запрете доступа, недоступности данных.
  - Интеграция с картой: Отображение местоположения на карте с использованием Yandex Maps.
- **Как найти**:
  - На странице настроек отображается карта с вашим текущим местоположением (при успешной загрузке).
- **Как работает**:
  - При успешном определении координат отображается карта с точкой на местоположении пользователя.
  - В случае запрета доступа выводится сообщение: "Вы запретили доступ к вашему местоположению".
  - При ошибках отображаются соответствующие уведомления.

### 14. Notifications API
Позволяют веб-приложениям получать и отображать push-уведомления
- **Что реализовано**:
  - Запрос разрешений: Используется **`Notification.requestPermission`**.
  - Локальные уведомления: Отправляются через Notification API.
  - Push-уведомления: Обрабатываются с помощью кастомного Service Worker (sw.js).
  - Обработка ошибок: Уведомления о запрете доступа или неподдерживаемом функционале.
  
- **Как найти**:
  - На главной странице приложения доступна кнопка "Отправить Push уведомление!".

- **Как работает**:
  - При первом использовании запрашивается разрешение на уведомления.
  - Push-уведомления отправляются через зарегистрированный Service Worker.
  - В случае ошибок (например, запрет на уведомления) выводятся предупреждения.

### 15. QR code reader

Позволяет обнаружить QR-код, используя камеру устройства.

- **Что реализовано:**
При наведении камеры на QR-код отображается результат сканирования (текст, содержащий сумму для оплаты).

- **Как найти:**
Выбрать пункт меню Платежи, Оплата по QR.

- **Требования:**
- Безопасный контекст: эта функция доступна только в безопасных контекстах (HTTPS).

### 16. Contact Picker Api

Позволяет получать контакты из телефоной книжки.

- **Как найти:**
  - В переводах по номеру телефона нажать на иконку в окне ввода номера телефона.

- **Как работает**:
  - Если устройство подходит под требования и Api поддерживается, то запуститься список с номерами телефона из контактой книжки и отображаются в инпут.
  - В случае если Api на Ios сразу не включен, откроется окно с инструкцией как подключить данное Api.

- **Требования:**
  - Браузер Chrome и на Android версии 6 и выше.
  - Браузер Safari и на Ios версии 15 и выше.
